        How to read the RICE tracker / About this data

        Scope: Jira project CONAMER1001932 RICE items for Wave 3, Release 1, Test Cycle P2. Withdrawn items are excluded. This tab does not mix in conversion objects or conversion-labeled defects.

        Delayed / On Target / Complete: Delayed if any incomplete sub-task is past Planned Complete Date. Complete if the parent is Completed or every sub-task is Completed. Everything else is On Target.

        Risk: High if at least one incomplete sub-task is past planned complete date. Watch and Stable follow the source RICE dashboard rules.

        Change requests: a CR is delivery-complete only when every linked defect is Resolved, Withdrawn, Closed, Cancelled, Rejected, or Done. CR Accepted is not delivery complete.

        Dates: overdue uses Planned Complete Date. Jira Due Date is unused on these sub-tasks. Snapshot date is 23 September 2026.

        System of record: Jira remains authoritative. This is a read-only snapshot; records cannot be edited in the dashboard.

        How to read the P2 Prep tracker / About this data

        Scope: Jira issues labeled P2-Prep are rolled up here; individual Jira tasks and the parent-child structure are intentionally not listed. Conversion objects and conversion defects are not mixed in. RICE delivery is summarized by workstream in its own table and sourced from the P2 RICE tracker.

        Technical vs Functional: Jira has no activity-type field, so each activity is classified from its own summary and its parent deliverable. Technical covers design documents, build, code, unit test, environment and instance work. Functional covers functional designs, KDDs, test case preparation, functional testing and business approvals. Anything governance-level is reported as PMO / Other.

        Completed vs planned: of activities whose due date is on or before the snapshot date, the share in a Done status category.

        Overdue: activities that are still open and have a due date before the snapshot date.

        RICE by workstream: Source to Pay, Acquire to Retire, and Plan to Report only. Complete / In Progress / Not Started uses each RICE item’s Jira status from the P2 RICE tracker. Drill into the P2 RICE Tracker tab for item-level detail.

        Dates: snapshot date is 22 September 2026. Due dates come from Jira.

        How to read this dashboard / About this data

        Conversion objects and subtasks: Jira Conversion Execution subtasks for Release 1 - P2. Withdrawn objects are excluded. The Executive Summary uses Data Conversion records only; Release 1 - P2 Prep never contributes to these metrics.

        Defects: all open Jira defects labeled conversion, including functional-team defects. On Hold defects remain in the open count and are labeled On Hold; they are not blockers.

        Risk: any past-due conversion subtask, plus any past-due open defect of Critical or High severity. Medium, Low, and On Hold items stay on the dashboard but are not raised as Risks. Recon-related work is excluded from Risks and Blockers because it does not gate downstream activity.

        Blocker: only an item whose Jira status is exactly Blocked. The dashboard does not infer blockers, and On Hold never counts as Blocked.

        Key blocker / issue: an overdue Extract-through-Load subtask with a Jira predecessor link to downstream work. No such links are present in this snapshot, so the section shows a readiness note instead of inferred results.

        % of Subtasks Complete: completed conversion subtasks ÷ all in-scope conversion subtasks. It is not an average of object statuses.

        Dates and freshness: defect Target Retest comes directly from Jira Due Date. Dates are being refreshed by the team. The timestamp above records the latest Jira refresh.

        System of record: Jira remains authoritative. This is a read-only daily snapshot; records cannot be edited in the dashboard.

        Out of scope: Jira Action Items are not included. This dashboard contains only Conversion Execution subtasks and open defects labeled conversion.
