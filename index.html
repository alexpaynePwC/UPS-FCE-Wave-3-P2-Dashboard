        How to read this dashboard / About this data

        Conversion objects and subtasks: Jira Conversion Execution subtasks for Release 1 - P2. Withdrawn objects are excluded. The Executive Summary uses Data Conversion records only; Release 1 - P2 Prep never contributes to these metrics.

        Defects: all open Jira defects labeled conversion, including functional-team defects. On Hold defects remain in the open count and are labeled On Hold; they are not blockers.

        Risk: any past-due conversion subtask or open defect. Recon-related work is excluded from Risks and Blockers because it does not gate downstream activity.

        Blocker: only an item whose Jira status is exactly Blocked. The dashboard does not infer blockers, and On Hold never counts as Blocked.

        Key blocker / issue: an overdue Extract-through-Load subtask with a Jira predecessor link to downstream work. No such links are present in this snapshot, so the section shows a readiness note instead of inferred results.

        % of Subtasks Complete: completed conversion subtasks ÷ all in-scope conversion subtasks. It is not an average of object statuses.

        Dates and freshness: defect Target Retest comes directly from Jira Due Date. Dates are being refreshed by the team. The timestamp above records the latest Jira refresh.

        System of record: Jira remains authoritative. This is a read-only daily snapshot; records cannot be edited in the dashboard.

        Out of scope: Jira Action Items are not included. This dashboard contains only Conversion Execution subtasks and open defects labeled conversion.
